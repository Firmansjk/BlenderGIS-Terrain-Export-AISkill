# BlenderGIS-Terrain-Export-AISkill
A Template for Automate Exporting a specific place on earth in BlenderGIS Terrain using the Skill.md and there is also a .blend template
# Blender version used
Blender 4.4.3
# How to Use
After telling Agent to use blendergis-terrain/skill.md, Input : 
- Latitude
- Longitude
- From Min
- From Max
- 
Get those data from https://heightmap.skydark.pl/
